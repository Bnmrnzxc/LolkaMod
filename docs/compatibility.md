# Обновления и восстановление

После обновления Lolka полностью закройте её, откройте установщик и снова нажмите «Установить / обновить». Запустите Lolka и проверьте штатное меню качества; диагностика открывается по Ctrl+Shift+M.

Установщик сохраняет новый оригинал клиента. Предыдущий backup остаётся отдельно в `resources/lolkamod-backup-*.asar`. Удаление мода восстанавливает текущий оригинал, а не предыдущую версию. Настройки пользователя сохраняются.

## Совместимость

Desktop проверяется по структуре ASAR, метаданным Lolka, CommonJS main `dist-js/main.js`, preload `dist-js/preload.js` и ожидаемым desktop IPC. Версия и SHA-256 оригинала сохраняются в manifest для каждой установки. Это проверка поддерживаемой формы интеграции, а не подлинности клиента.

Известный renderer имеет быстрый путь. Другие сборки Acorn разбирает без исполнения кода. Сопоставление токенов учитывает переименования локальных переменных, пробелы и комментарии. Проверяются уникальность участков, общие ссылки, значения 720/1080/1440 и 30/60, таблица размеров, вызовы списков качества в одном компоненте и применение параметров encoder. Все девять патчей применяются вместе; готовый ESM проверяется на синтаксис. Глобальные auth/premium stores не изменяются.

Изменение API, структуры выражений, размеров, разделение кода по модулям или неоднозначные совпадения требуют новой версии адаптера. При несовместимости исходный интерфейс загружается без патчей качества. Повторная установка того же EXE не исправляет изменившиеся API. Статус последней проверки сохраняется в `resources/lolkamod/compatibility.json` без исходного bundle и данных аккаунта.

## Восстановление

Операции используют staging, хеши снимков и journal `.lolkamod-transaction.json`. Следующий запуск установщика восстанавливает состояние прерванной операции, если снимки и текущие файлы соответствуют ожидаемым. Изменённые посторонней программой файлы он не затирает. Не удаляйте journal или staging вручную до восстановления.

Если собственный shim остался, а backup или manifest повреждён, сохраните файлы и переустановите официальный клиент, затем примените мод. Пока мод активен, встроенное автообновление приостановлено; для обычного обновления можно предварительно удалить мод.

Проверки используют Lolka 1.0.120, искусственную смену версии/архива и пересборку веб-интерфейса с переименованными переменными. Это не приёмка всех будущих версий и не подтверждение реального 1440p/60 у удалённого зрителя. Установщик распространяется без цифровой подписи.
