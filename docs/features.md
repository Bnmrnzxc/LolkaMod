# Возможности и границы LolkaMod

Настройки открываются в Lolka → LolkaMod. Ctrl+Shift+M сохраняется как резервный вход, если текущий интерфейс клиента не совместим с встраиванием.

## Темы и настройки

Доступны 24 готовые темы. Значок палитры открывает редактор своей темы: тёмный/светлый вид, до четырёх цветов, HEX, оттенок и насыщенность. Несколько цветов создают градиент. Изменения применяются сразу и сохраняются после перезапуска. «Оформление Lolka» возвращает штатную тему, сохраняя свою палитру; собственный CSS применяется поверх выбранного оформления.

Переключатели сохраняются локально. Старый файл настроек переносится в schema 1 с резервной копией при первой записи. Настройки schema 1 без своей палитры сохраняют прежнюю тему и получают дефолт редактора. Повреждённая или более новая схема не перезаписывается обычным сохранением: доступен явный сброс с сохранением оригинала.

## Индикатор

Значок у стрима показывает показатели при наведении или фокусе. Метрики относятся к выбранному video track. Capture FPS — настройка захвата; encoded/decoded FPS — данные RTP или дельта кадров. Данные обновляются одним collector. Недоступные значения не заменяются выбранным режимом меню: выбранный профиль подписан отдельно. Для native захвата без доступных RTP stats показывается соответствующий статус.

## Меню стрима

Стрелка у штатной кнопки открывает выбор источника и качества, управление индикатором и остановку. Основная кнопка Lolka продолжает использовать её штатное действие. Меню не добавляет управления голосом или звуком.

Качество применяется штатным setter активной трансляции сразу после выбора, без кнопки подтверждения. Во время операции поля временно отключены. После успешного применения сохраняются обычные ключи Lolka. Выбор источника открывается до остановки: отмена сохраняет стрим. После выбора выполняется последовательный stop/start, поэтому зритель может увидеть краткое прерывание. Если новый захват не запускается, клиент показывает ошибку; автоматический возврат к старому источнику не гарантирован.

## Обновления

Проверка выполняется вручную через публичный GitHub Releases/latest. Нет авторизации, телеметрии и автоматической загрузки/запуска установщика. Ссылка ограничена релизами Bnmrnzxc/LolkaMod; main не принимает произвольный URL из renderer. Штатный автообновлятор Lolka остаётся приостановленным.

## Проверка перед обычным использованием

Разработка проверяет изолированную копию, штатные settings/picker, перезапуск и локальный WebRTC. Смена источника в реальном SFU-сеансе и качество у друга требуют пользовательской проверки. [Проверка стрима](stream-test.md).
