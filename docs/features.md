# Возможности и границы LolkaMod

Настройки открываются в Lolka → LolkaMod. Ctrl+Shift+M сохраняется как резервный вход, если текущий интерфейс клиента не совместим с встраиванием.

## Темы и настройки

Тема и переключатели сохраняются локально. «Штатная» снимает оформление мода; собственный CSS применяется поверх выбранной темы. Старый файл настроек переносится в schema 1 с резервной копией при первой записи. Повреждённая или более новая схема не перезаписывается обычным сохранением: доступен явный сброс с сохранением оригинала.

## Индикатор

Карточка различает исходящее и входящее видео. Capture FPS — настройка захвата; encoded/decoded FPS — данные RTP или дельта кадров. Данные обновляются одним collector. Недоступные значения не заменяются выбранным режимом меню. Для native захвата без доступных RTP stats показывается соответствующий статус. Входящее видео без надёжной связи с конкретным стримом помечается как неизвестный источник.

## Меню стрима

Стрелка у штатной кнопки открывает выбор источника, качества и мини-плеера, управление индикатором и остановку. Основная кнопка Lolka продолжает использовать её штатное действие. Меню не добавляет управления голосом или звуком.

Качество применяется штатным setter активной трансляции. После успешного применения сохраняются обычные ключи Lolka. Выбор источника открывается до остановки: отмена сохраняет стрим. После выбора выполняется последовательный stop/start, поэтому зритель может увидеть краткое прерывание. Если новый захват не запускается, клиент показывает ошибку; автоматический возврат к старому источнику не гарантирован.

## Мини-плеер

Используется явно выбранное видео из штатного реестра экранных трансляций. Если клиент поддерживает своё PiP-окно, вызывается его менеджер; иначе используется Picture-in-Picture существующего HTMLVideoElement. Новые capture, peer connections и аудиоплееры не создаются. Закрытие снимает только принадлежащий моду PiP. Доступность зависит от сборки клиента и готовности видео.

## Обновления

Проверка выполняется вручную через публичный GitHub Releases/latest. Нет авторизации, телеметрии и автоматической загрузки/запуска установщика. Ссылка ограничена релизами Bnmrnzxc/LolkaMod; main не принимает произвольный URL из renderer. Штатный автообновлятор Lolka остаётся приостановленным.

## Проверка перед обычным использованием

Разработка проверяет изолированную копию, штатные settings/picker, перезапуск и локальный WebRTC. Смена источника в реальном SFU-сеансе, окно PiP с настоящим стримом и качество у друга требуют пользовательской проверки. [Проверка стрима](stream-test.md).
