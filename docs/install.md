# Установка LolkaMod

Сначала установите обычную Lolka и полностью закройте её. LolkaMod устанавливается поверх готового клиента.

## macOS · Apple Silicon

Требуется macOS 13 или новее.

Откройте DMG, перенесите **LolkaMod Installer** в Applications и запустите его. Выберите **Lolka.app**, затем **«Установить / обновить»**.

Установщик не имеет Developer ID. Если macOS заблокировала первый запуск, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** для LolkaMod. После патча macOS может повторно запросить разрешение Lolka на запись экрана.

Если нет прав на изменение Lolka.app, перенесите её в **~/Applications** и выберите новый путь. Установщик сохраняет полную резервную копию рядом с приложением; **«Удалить мод»** восстанавливает оригинал.

## Linux · x64

Установите DEB или RPM через менеджер пакетов, затем запустите **LolkaMod** из меню приложений. Укажите папку Lolka (обычно **/opt/Lolka**) и нажмите **«Установить / обновить»**. Для системной установки появится обычный запрос прав администратора.

Для штатного пакета Lolka установщик убирает групповую запись у двух папок приложения, принадлежащих root. Остальные системные каталоги он не меняет.

Для захвата экрана нужны поддерживаемые Lolka PipeWire/desktop portal или X11. Используется штатный выбор источника клиента.

## Обновление и удаление

После обновления Lolka снова запустите установщик и примените мод. **«Удалить мод»** возвращает оригинальный клиент; **«Восстановить Lolka»** помогает восстановить проверенную резервную копию при повреждении патча.
