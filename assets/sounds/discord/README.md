# Classic Discord action sounds

`classic.json` contains the 15 classic action/notification MP3s used by LolkaMod,
encoded as Base64. The build embeds this pack only in the main-process payload.
Enabling the theme makes no sound-download requests.

`provenance.json` records the original public Discord URLs, semantic keys,
byte counts, SHA-256 hashes and bootstrap mapping evidence. These assets are
Discord content and are excluded from the project's MIT license.
LolkaMod is not affiliated with Discord. See `THIRD_PARTY_NOTICES.md`.
