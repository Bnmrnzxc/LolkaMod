# LolkaMod

Мод для Lolka на Windows. Открывает **1080p, 1440p и 60 FPS** в обычном меню стрима. Выбранное качество сохраняется после перезапуска — достаточно установить мод один раз.

**[Скачать установщик](https://github.com/Bnmrnzxc/LolkaMod/releases/latest/download/LolkaModInstaller-0.3.0.exe)** · [Открыть релиз](https://github.com/Bnmrnzxc/LolkaMod/releases/latest)

Поддерживается **Lolka 1.0.120 · Windows x64**.

## Установка

1. Полностью закройте Lolka, включая значок в трее.
2. Запустите скачанный установщик и нажмите **«Установить / обновить»**.
3. Откройте Lolka и выберите нужное качество в штатном меню стрима.

Панель с настройками CSS и диагностикой открывается по **Ctrl+Shift+M**.

## Удаление и обновления

Чтобы удалить мод, закройте Lolka и нажмите **«Удалить мод»** в том же установщике. Настройки Lolka сохранятся.

Пока мод установлен, автообновления Lolka приостановлены. Перед обновлением клиента удалите мод; для новой версии может понадобиться обновлённый патч.

Сборка экспериментальная: 1440p проверено локально, качество у зрителя и стабильные 60 FPS пока не подтверждены.
