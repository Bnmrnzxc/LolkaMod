# LolkaMod

Мод для **Lolka**: стримы до 1440p и 60 FPS, темы и дополнительные настройки.

**[Windows](https://github.com/Bnmrnzxc/LolkaMod/releases/latest/download/LolkaModInstaller.exe)** · **[macOS · Apple Silicon](https://github.com/Bnmrnzxc/LolkaMod/releases/latest/download/LolkaModInstaller-arm64.dmg)** · **Linux: [DEB](https://github.com/Bnmrnzxc/LolkaMod/releases/latest/download/LolkaModInstaller-amd64.deb) / [RPM](https://github.com/Bnmrnzxc/LolkaMod/releases/latest/download/LolkaModInstaller-x86_64.rpm)**

## Возможности

- **1080p, 1440p и 60 FPS** в штатном меню стрима.
- Смена источника и качества во время трансляции. Качество применяется сразу.
- Индикатор качества стрима с показателями при наведении.
- **24 готовые темы** и редактор собственной палитры.
- Раздел **LolkaMod** в настройках и пользовательский CSS для оформления.
- **Звуки Discord** для уведомлений, звонков и действий — одним переключателем. Набор встроен в мод.
- Проверка обновлений в настройках и предложение обновиться при запуске установщика.

## Установка

1. Полностью закройте Lolka, включая значок в трее.
2. Запустите установщик и нажмите **«Установить / обновить»**.
3. Откройте Lolka. Настройки мода доступны в разделе **LolkaMod** и по **Ctrl+Shift+M**.

Windows и Linux — x64, macOS — Apple Silicon. Удалить мод можно тем же установщиком. [Установка на macOS и Linux](docs/install.md).

После обновления Lolka повторите установку мода. Автообновление клиента при установленном моде приостановлено.
