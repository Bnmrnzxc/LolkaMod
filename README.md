# LolkaMod

Неофициальный мод для **Lolka на Windows**. Добавляет удобные настройки и возможности стримов прямо в привычный интерфейс приложения.

**[Скачать для Windows](https://github.com/Bnmrnzxc/LolkaMod/releases/download/v0.5.0/LolkaModInstaller-0.5.0.exe)** · [Все релизы](https://github.com/Bnmrnzxc/LolkaMod/releases)

## Возможности

- **1080p, 1440p и 60 FPS** в штатном меню стрима.
- Раздел **LolkaMod** в настройках приложения.
- Индикатор разрешения, FPS, кодека и битрейта, когда эти данные доступны.
- Готовые темы: графит, AMOLED и высокий контраст, а также пользовательский CSS.
- Мини-плеер для просмотра видео в отдельном окне.
- Меню стрима: смена источника и качества, мини-плеер и остановка трансляции.
- Ручная проверка обновлений мода.

Настройки сохраняются после перезапуска. Голос и обработку микрофона мод не меняет.

## Установка

1. Полностью закройте Lolka, включая значок в трее.
2. Запустите установщик и нажмите **«Установить / обновить»**.
3. Откройте Lolka. Настройки мода доступны в разделе **LolkaMod** и по **Ctrl+Shift+M**.

Для Windows x64. Чтобы удалить мод, воспользуйтесь кнопкой **«Удалить мод»** в установщике.

После обновления Lolka можно повторно применить патч тем же установщиком. При крупных изменениях клиента потребуется обновление LolkaMod. Автообновление Lolka при установленном моде приостановлено.

Проект экспериментальный. Качество стрима зависит от источника, устройства и соединения. Смена источника кратко перезапускает трансляцию.
