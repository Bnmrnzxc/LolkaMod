# LolkaMod

Неофициальный мод для **Lolka на Windows**. Расширяет возможности стримов и добавляет настройки прямо в приложение.

**[Скачать установщик](https://github.com/Bnmrnzxc/LolkaMod/releases/latest/download/LolkaModInstaller.exe)** · [Страница релиза](https://github.com/Bnmrnzxc/LolkaMod/releases/latest)

## Возможности

- **1080p, 1440p и 60 FPS** в штатном выборе качества.
- Смена источника и качества во время стрима. Качество применяется сразу после выбора.
- Компактный значок качества рядом со стримом — показатели видны при наведении.
- Раздел **LolkaMod** в настройках, 24 готовые темы, своя палитра и пользовательский CSS.
- Ручная проверка обновлений мода.

Настройки сохраняются после перезапуска. Голос и обработку микрофона мод не меняет.

## Установка

1. Полностью закройте Lolka, включая значок в трее.
2. Запустите установщик и нажмите **«Установить / обновить»**.
3. Откройте Lolka. Настройки мода доступны в разделе **LolkaMod** и по **Ctrl+Shift+M**.

Для Windows x64. Удалить мод можно тем же установщиком.

После обновления Lolka повторно примените патч. При крупных изменениях клиента потребуется новая версия LolkaMod. Автообновление Lolka при установленном моде приостановлено.

Проект экспериментальный. Качество зависит от источника, устройства и соединения; смена источника кратко перезапускает стрим.
