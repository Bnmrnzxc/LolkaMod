# LolkaMod

Мод для Lolka на Windows. Открывает **1080p, 1440p и 60 FPS** в обычном меню стрима. Выбранное качество сохраняется после перезапуска — достаточно установить мод один раз.

**[Скачать установщик](https://github.com/Bnmrnzxc/LolkaMod/releases/download/v0.4.0/LolkaModInstaller-0.4.0.exe)** · [Открыть релиз](https://github.com/Bnmrnzxc/LolkaMod/releases/latest)

Для **Windows x64**. Проверено на Lolka 1.0.120; совместимость других сборок проверяется при установке и запуске.

## Установка

1. Полностью закройте Lolka, включая значок в трее.
2. Запустите скачанный установщик и нажмите **«Установить / обновить»**.
3. Откройте Lolka и выберите нужное качество в штатном меню стрима.

Панель с настройками CSS и диагностикой открывается по **Ctrl+Shift+M**.

## Удаление и обновления

Чтобы удалить мод, закройте Lolka и нажмите **«Удалить мод»** в том же установщике. Настройки Lolka сохранятся.

После обновления Lolka закройте её и снова нажмите **«Установить / обновить»**. Установщик сохранит новый оригинал и вернёт мод, если структура клиента совместима. Мелкие изменения интерфейса и переименования переменных обрабатываются автоматически.

Автообновления Lolka при установленном моде приостановлены. При существенных изменениях потребуется новая версия LolkaMod. Подробнее: [совместимость и восстановление](docs/compatibility.md).

Сборка экспериментальная: 1440p проверено локально, качество у зрителя и стабильные 60 FPS пока не подтверждены.
